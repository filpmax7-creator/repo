FloatSnap OCR uses Tesseract 4.1.0 and Leptonica 1.79.0 from SwiftyTesseract/libtesseract release 0.2.0 (iOS arm64 slice), libpng 1.6.36, libtiff 4.0.10, and IJG libjpeg 9c. This software is based in part on the work of the Independent JPEG Group. The system zlib/iconv libraries are dynamically linked. Arabic model: tesseract-ocr/tessdata_best; English model: tessdata_fast. All inference is offline. See the accompanying licenses.
